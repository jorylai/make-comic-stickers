# 图片转漫画贴纸工坊

## 执行顺序

1. 读取用户提供的任意图片、可选风格参考和印刷店格式。接受照片、截图、插画以及单图或多图；不要求先有透明背景。优先延续已经确认的主体、画风、文案与尺寸，仅在关键参考缺失时索取。区分输入图的主体内容与风格图的绘画手法。
2. 建立主体说明：人物记录脸型、发型、服装和配件；动物记录体型、花色和特征；物品记录外形、结构、配色和材质；风景或建筑记录轮廓、构图和标志细节。多主体图片按用户意图保留组合或拆成独立贴纸；未指定时保留原组合。只有用户提出时才给物品添加眼睛、肢体或拟人表情，不把所有输入强制变成动物或大眼角色。
3. 把版本拆成不同主题，再为每套逐枚写出动作、道具、表情与短句。用户指定数量时按要求制作；泛指“做一套”时默认一套十二枚，仅在请求五套或更多版本时扩展数量。物品、食物、建筑等可通过角度、组合、装饰与场景变化形成版本，无需强行创造肢体动作。读取 [风格与提示词](references/design-prompts.md) 和 [主题文案](references/themes-and-copy.md)。
4. 使用当前环境的图像生成/编辑工具将输入图片改绘为漫画贴纸，显式传入原图和可用风格参考。按用户要求选择漫画画风；无风格要求时采用轮廓清晰、色彩明快的可爱漫画风，不固定毛绒动物画风。通过图像工具分离主体并输出透明 PNG；风景或完整场景可保留为有明确外边界的场景贴纸。输入 JPEG 或有背景图片也必须完成此转换，不能直接交给仅接受透明素材的排版脚本。优先单枚生成；成套生成时采用明确的 3 列 × 4 行、透明背景与宽留白。先检查辨识度与画风，再做全批次。
5. 按主体检查结构完整性：人物或动物的肢体、物品的组成、建筑和场景的形状，以及道具和图文对应关系。文案可选；无文案时不擅自添加。中文不准确时用可用中文字体重新排字，或让图像工具单独修正；不要交付错字或乱码。使用文案时保留 UTF-8 原文。
6. 将确认的透明插画及文案作为一个整体排版。按 [生产规范与配置](references/production.md) 调用脚本，生成精确尺寸的印刷文件；不要依赖生成模型画出的毫米比例或刀模。
7. 逐套检查完整预览，并放大检查所有图案及中文。运行几何和文件校验。修复裁切、跨格串文案、分离道具、闭合失败和间距不足后重导出。
8. 交付手机可浏览的图和 ZIP 印刷包，说明印刷用无红线 PNG、红色刀模单独提供且不参与印刷。遵循当前环境的文件保存流程。不要把生成图分辨率不足包装成原生高分辨率。

## 默认生产参数

| 项目 | 默认值 |
|---|---|
| 纸张 | 140 × 210 mm，竖版 |
| 排列 | 每套 3 × 4，共 12 枚 |
| 插画与文字 | 位图；RGB 白底印刷 PNG |
| 输出画布 | 600 dpi，3307 × 4961 px |
| 刀模 | 红色 `#ff0000`，闭合矢量 SVG，独立文件 |
| 外扩白边 | 2 mm；脚本采用 2.08 mm 作为描摹余量 |
| 间距 | 刀模之间至少 4 mm；比只检查物体间距更严格 |
| 两侧留白 | 默认至少 8 mm |
| 手机图 | 无红线与红线校对 JPG 各一份 |

以用户或印刷店的明确要求覆盖默认。把每个文字、爱心、星星和道具纳入对应图案的同一条闭合刀模，避免产生独立小碎片。需要桥接时检查白色连接区域是否自然。

## 运行脚本

漫画改绘依赖可用的图像生成/编辑工具；随包 Python 脚本只负责透明成品素材的拆分、排版、描边与导出，不独立运行图像模型。无图像工具时可处理已有漫画 PNG，不能声称已把照片改成漫画。

生产脚本依赖 Python 3、Pillow、NumPy、SciPy 和系统共享库 libpotrace；使用 `ctypes.util.find_library` 自动寻找 Potrace。先检查依赖，不静默安装。

```bash
python3 scripts/build_sticker_pack.py --config /absolute/path/job.json --output /absolute/path/output
python3 scripts/validate_pack.py /absolute/path/output
```

把 [示例配置](assets/job.example.json) 复制到工作目录并替换图片路径。相对路径按配置文件目录解析。优先使用 `assets` 独立透明图输入，包含文案的素材可避免自动拆图串位；只有排布整齐的源图才使用 `source_grid`。

源图拆分支持 `heading_shift_px` 修正文案跨越名义行边界。此值必须从实际源图观察得到，禁止把某次历史图片的修正数值套给新图。检查提取出的逐枚 PNG 后再确认排版。

## 不可省略的检查

- 保持输入主体的辨识特征和用户选定的漫画画风。不要继承其他项目的三花猫花色、毛绒质感、大眼比例、动物口吻或特定配件。示例只用于说明，不限制输入类型。
- 位图插画加矢量刀模不等于插画矢量化。用户要求真矢量插画时，另外描摹并检查路径；禁止把嵌入 PNG 的 SVG 称为真矢量图。
- 600 dpi 仅表示输出画布的像素密度；记录原素材像素和缩放比例，说明细节受原素材限制。
- 检查独立刀模闭合、数量与图案一致、图形全部在页内、最小间距和两侧留白达标。以脚本输出的保守包围框间距作验收下限。
- 所有正式文件先写临时文件，重新打开或解析验证后原子替换，避免大文件写到一半被读取。
- 不上传原照、私人路径、下载签名、账号信息或历史成品到共享代码仓库，除非用户明确要求。新主题不自动获得公开发布用户照片的授权。
- 若生成工具拒绝某主题，准确告知并使用实质不同的可行主题；不得尝试绕过拦截，也不得编造拦截原因。
