# 主题与可选文案

按输入主体与用户用途组织主题，不把所有任务固定为打工猫。文案可选：需要纯图时留空；人物、物品、品牌或风景使用合适语气，不自动添加“喵”。

| 输入示例 | 版本方向 | 可选短句 |
|---|---|---|
| 人物肖像 | 日常表情、工作鼓励、自信夸夸、节日祝福 | 我可以的／今天也漂亮／收到啦／谢谢你 |
| 宠物或动物 | 日常动作、玩耍、睡觉、拟人小剧场 | 开饭啦／休息一下／快乐出逃；动物口吻按需使用 |
| 咖啡杯、食物 | 不同角度、套餐组合、早餐、下午茶 | 今日补给／来点甜／慢慢享用 |
| 植物、花束 | 生长状态、季节、花器、花叶组合 | 好好生长／今天开花／送你一束 |
| 背包、玩具、日用品 | 功能场景、摆放姿态、系列配色 | 出发吧／一起冒险；也可纯图 |
| 建筑、旅行照片 | 地标、季节、昼夜、路线与场景组合 | 城市漫游／看个日落／下一站快乐 |
| 多主体合照 | 保留组合、互动、纪念日；按要求拆分人物 | 一起出发／我们最棒／纪念这一天 |

若用户未指定数量，先按一套十二枚规划。仅在要求多个版本时按主题扩展。用动作、角度、配件、布局或环境形成差异，避免只换文案。短句通常控制在约 3–9 个汉字，按主体气质和用途调整，不必固定为夸自己或打工语录。

猫咪示例仅是一种应用：三花猫的花色和毛绒风格来自对应原图与风格参考，不属于其他任务的默认参数。
