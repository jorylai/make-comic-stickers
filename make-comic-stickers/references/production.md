# 生产规范与配置

## 输入

整个 skill 接受任意内容图片；这里的生产脚本接收的是经过漫画改绘和背景处理后的透明 PNG。不要把脚本的透明输入要求误写成 skill 只支持透明图片。主体可以是人物、动物、物品、食物、建筑或完整场景。图片转漫画与背景处理由图像工具完成。

脚本接受 JSON。默认 140×210 mm、600 dpi、3列4行，支持其他纸张尺寸、行列和每套数量。每套选择一个输入方式：

1. `assets`：独立透明 PNG 路径列表，包含已经确认的文字和插画，推荐。
2. `source_grid`：透明且布局规则的源图；`heading_shift_px` 只用于源图的跨行标题修正。拆图以 alpha 连通域和临近主体分配；不能代替人工检查。

`captions` 仅用于记录和校对，脚本不会自动绘制中文。使用文案时必须先将文字合入对应 PNG；纯图任务省略 `captions` 或使用等长空字符串列表。脚本会拒绝没有透明背景的素材，防止把整张背景矩形当作贴纸。

准备运行环境时，通过该环境认可的方式安装 `scripts/requirements.txt` 中的 Python 依赖，以及系统共享库 libpotrace。当前 ctypes 绑定要求 `unsigned long` 为 64 位，适用于常见 64 位 Linux/macOS；Windows 的 ABI 不符合此条件，改用 WSL/Linux 或另写兼容的 Potrace 适配层。图像生成工具不是此 Python 脚本的组成部分，部署平台应提供可创作/编辑参考图的能力。没有图像工具时仍可处理已有透明 PNG。

```json
{
  "sheet_mm": [140, 210],
  "dpi": 600,
  "columns": 3,
  "rows": 4,
  "offset_mm": 2.08,
  "min_gap_mm": 4,
  "side_margin_mm": 8,
  "themes": [{
    "id": "01_comic_mix",
    "title": "漫画贴纸素材集",
    "assets": ["art/01.png", "art/02.png"],
    "captions": ["今天真棒", "快乐出发"]
  }]
}
```

支持 `max_art_mm` 控制单枚插画最大尺寸；默认按格大小扣除刀模和间距。默认每套不超过行列容纳数。相对图片路径以 JSON 所在目录为基准。

## 算法与边界

1. 清理透明边界，按毫米缩放插画，保留足够的外扩画布。
2. 使用 alpha 阈值 96 提取图文整体掩膜。
3. 用距离变换产生指定毫米的外扩白边，填补内部孔洞。
4. 对文字、爱心等分离部分添加最短连接桥，直到该枚只有一个外轮廓。白色桥接会改变局部外扩形状；逐枚目检，必要时先重排素材。
5. 用 Potrace 将外轮廓描摹成平滑闭合 Bézier 路径，生成独立红色 SVG。
6. 以刀模包围框距离作保守间距下限；达标则实际刀模距离至少达标，未达标直接停止并要求调整布局。检查四边是否越界与两侧留白。
7. 导出无红线 PNG、红线与无红线手机 JPG、逐枚提取 PNG、几何报告与 UTF-8 文案，验证后打包 ZIP。

刀模线宽默认 0.10 mm。SVG 的物理尺寸以 mm 标明。打印店可以导入并映射为专色刀模通道；本脚本不承诺 SVG 自动等同于该店的专色印前设置。交付时说明红线不印刷，避免误印。

## 运行与验证

```bash
python3 scripts/build_sticker_pack.py --config job.json --output output
python3 scripts/validate_pack.py output
```

`GEOMETRY_AND_CAPTIONS.json` 记录输出尺寸、源像素、缩放倍数、闭合轮廓数量、间距和留白。源图细节受原素材分辨率限制；把 1024px 图放进 600 dpi 版面不会创造原生高清细节。

脚本保留 `_extracted/` 的逐枚素材便于审核，印刷 ZIP 不包含这些中间文件。正式交付包含每套四个文件、几何报告、文字原文和打印说明。

默认 PNG 是 RGB。需要 CMYK、出血、专色名或特定 PDF/X 时依据印刷店给定的 ICC 与规格另外处理；不要猜测色彩配置后宣称满足印厂认证。
