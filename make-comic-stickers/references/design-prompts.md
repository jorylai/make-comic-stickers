# 风格与提示词

## 主体与画风

先辨认输入类型，再提取视觉特征。主体参考决定“画什么”，风格参考决定“怎么画”；不可用风格图中的角色替换输入主体。

| 输入 | 保留特征 | 可生成变化 |
|---|---|---|
| 人物、合照 | 脸型、发型、服饰、配件、人物关系 | 表情、动作、服装场景；保持人物辨识度 |
| 宠物、其他动物 | 体型、花色、耳朵、眼睛、标志性斑纹 | 姿态、表情、活动场景 |
| 物品、食物、植物 | 轮廓、结构、色彩、材质或叶形 | 角度、组合、包装、装饰；拟人化须有用户意图 |
| 建筑、风景、复杂场景 | 标志轮廓、布局、地貌、主要色彩 | 季节、光照、构图、漫画分镜式边界 |
| 已有插画或设计图 | 原有角色、造型和风格约束 | 按要求漫画化、扩展或直接制作贴纸版 |

支持可爱手绘、Q版、日系漫画、黑白线稿、复古漫画、平涂等用户指定风格；无要求时使用干净、轮廓清晰、明快的可爱漫画风。不要给所有主体统一套用猫眼、毛发、猫爪或动物耳朵。

## 单枚提示词骨架

> 根据附带输入图，把 [主体描述] 改绘为 [漫画风格] 的贴纸。保留辨识特征：[关键特征]。参考风格图仅延续绘画手法。内容/姿态/角度：[变化]；场景与道具：[内容]。文案：[明确写出短句或“不要文字”]。图文作为一个紧凑完整单元，保持结构准确与可读性，周围留足透明区域，透明背景。不要画刀模线、纸张边框、可见网格或水印。

输入为有背景照片时，通过图像编辑工具把主体与无关背景分离。风景或多主体需要保留整体时，将选定场景组织成一个完整场景贴纸，周围透明，不把画面中每个物体误拆成独立刀模。

如果工具不适合生成准确中文，先生成无字插画，再用覆盖中文的字体排字或单独生成文字贴图；核对后合并。没有文案需求则不加字。

## 整套提示词骨架

> 制作 [数量] 枚独立漫画贴纸的源素材板，[列数] 列 × [行数] 行，行优先顺序。基于附带输入图维持主体辨识度及统一画风。每格只放一枚，所有图案互不接触，文字和道具都归属本格，格间宽留白，四边透明，不画可见网格。逐格内容：1.[内容+可选文字]……。不要画刀模、尺寸线、纸张底色或背景投影。

源图是创意素材板，精确印刷尺寸与红线由生产脚本确定。检查 alpha 通道；查看器用黑色或棕色表示透明区时，不要直接断定背景不透明。

## 目视验收

- 手机缩略图中仍能辨认主体、动作或角度。
- 文案逐字正确；无文案的任务不多出文字。
- 主体结构完整、没有无意改变类别或无关配件。
- 同套保持风格一致；需要多个版本时有实际视觉变化。
- 源图拆分后文字、配件和场景元素未被分配给相邻图案。
