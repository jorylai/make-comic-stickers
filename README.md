# make-comic-stickers 🎨 任意照片 → 整版印刷贴纸

**一张照片进去，一整版能直接下单印刷的贴纸出来——连淘宝店家要另收费的刀模线，都给你画好了。**

在淘宝定做异形贴纸，通常是这个流程：你出图，店家报价，刀模（刀工线）单独算钱，来回发文件确认。钱不算多，但慢，而且最容易翻车的恰恰是刀模：白边多宽、间距够不够、线闭没闭合，不懂印前的人很难自查。

这个 skill 把整件事交给 Agent 跑完：照片改绘成漫画贴纸、成套变奏、按毫米排版、自动生成刀模线、逐项几何校验，最后交付一个能直接发给印厂的印刷包。

## 它能做什么

- **任意照片变漫画贴纸**：人物、宠物、动物、物品、食物、植物、建筑、风景、多人合照都行，不限猫咪，不强制拟人化
- **一套 12 枚自动变奏**：按主题拆分动作、表情、道具和短句文案（文案可选，不要就不加）
- **毫米级精确排版**：默认 140 × 210 mm 竖版、600 dpi、3307 × 4961 px 的 RGB 印刷 PNG，尺寸写进脚本、不靠模型"画"比例
- **免费刀模线**：每枚贴纸一条独立闭合的红色矢量刀模（`#ff0000` SVG），印厂可直接导入并映射为专色刀模通道；换一套图，刀模自动重新生成，不用再付一次刀工钱
- **白边与间距自动达标**：白边外扩约 2 mm、刀模之间至少 4 mm、两侧留白至少 8 mm，不达标脚本直接报错、不交付
- **手机预览 + 印刷包**：带红线校对图、无红线预览图各一份，外加 ZIP 印刷包，手机上就能确认效果

## 怎么用

1. 把 `make-comic-stickers/` 文件夹放进你的 Agent skills 目录（适用于支持 `SKILL.md` 的环境，如 Claude Code、Codex 等）
2. 把照片发给 Agent，说一句：**「用 make-comic-stickers 把这张照片做成贴纸」**
3. 收到的交付物直接发印厂或淘宝店：印刷 PNG + 刀模 SVG + 预览图，只付印刷费

## 工作原理

```
照片 → 图像模型改绘（漫画化 + 透明 PNG）
     → Python 脚本排版（毫米缩放 / 白边外扩 / 图文整体合并）
     → Potrace 描摹闭合刀模（红色矢量 SVG，独立文件、不参与印刷）
     → 几何校验（闭合 / 间距 / 留白 / 页内）→ 预览图 + 印刷包 ZIP
```

环境依赖：Python 3、Pillow、NumPy、SciPy 和系统库 libpotrace（见 `make-comic-stickers/scripts/requirements.txt`）。照片转漫画这一步需要运行环境带图像生成/编辑工具；没有图像工具时，脚本仍可处理已有的透明 PNG 素材。

## 默认生产参数

| 项目 | 默认值 |
|---|---|
| 纸张 | 140 × 210 mm，竖版 |
| 排列 | 每套 3 × 4，共 12 枚 |
| 印刷稿 | 600 dpi，3307 × 4961 px，RGB 白底 PNG |
| 刀模 | 红色 `#ff0000` 闭合矢量 SVG，独立文件 |
| 白边 | 外扩约 2 mm |
| 间距 | 刀模之间至少 4 mm，两侧留白至少 8 mm |

纸张、行列、尺寸都可改，印厂有明确要求时以印厂为准。

## 说清楚的几件事

- 600 dpi 指的是输出画布的像素密度，细节上限取决于原图分辨率——小图放大不会变出原生高清
- 位图插画 + 矢量刀模 ≠ 矢量插画；需要真矢量插画要另外描摹
- 默认输出 RGB；印厂要求 CMYK、出血或专色名时，按印厂给的规格另行处理
- 红色刀模线是单独文件，**不要合并进印刷图**，避免被误印出来
